# BTSP Lab

A computational neuroscience project studying how behavioral timescale synaptic plasticity (BTSP) shapes representations in a hippocampal CA3–CA1 model. The code supports configurable environments, optional spike timing dependent plasticity (STDP), and reinforcement learning readouts.

See the [development branch](https://github.com/nbainaev/btsp_stdp_article/tree/dev) for source code, experiment configurations, and setup instructions.
